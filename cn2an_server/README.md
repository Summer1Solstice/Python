# cn2an_server
## 使用方法
### 启动服务
运行`__main__.py`，传入参数，`-h`查看帮助。  
**常见用法：**  
`Python __main__.py 11233 --bind 127.0.0.1`，在本地`11233`端口启动服务。  
默认端口：`11233`，默认绑定地址：`127.0.0.1`。
### 访问服务
**查询参数**
#### `text`
- 说明：需要转换的字符串
- 类型：字符串
- 必填：是
#### `mode`
- 说明：转换模式
- 类型：字符串
- 必填：否
- 默认值与相关函数一致
#### `direct`
- `cn2an.transform`所需参数
- 类型：bool
- 必填：否  
#### 返回结果
结果为JSON格式，包含以下字段：
- `output`：转换结果
- `msg`：转换信息，包含错误信息时`output`为空。
